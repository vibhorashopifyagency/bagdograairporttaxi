# Google Search Central documentation changes, 2025–2026

From https://developers.google.com/search/updates (checked 21 October 2026).
Use it to see whether a rule in the other files may have moved, and re-fetch
the source page when it has. Newest first.

## 2026

- **16 Oct** Indexing API quota page updated.
- **8 Oct** UGC Fresh Data Program page added.
- **1 Oct** Generative-AI content guidance updated with Search Quality Rater
  Guidelines references (sections 4.6.5, 4.6.6).
- **24 Sep** VideoObject gains `creator` (with `author` support);
  `interactionStatistic` updated.
- **18 Sep** Aggregator and supplier units now support local-business
  queries (EEA).
- **16 Sep** Guide for a Search profile badge on your website.
- **8 Sep** "Regional differences in Search experience" hub (EEA, Türkiye,
  South Africa: aggregator units, supplier units, carousels).
- **28 Aug** Supported favicon formats listed explicitly; site reputation
  abuse enforcement adjusted in the EEA.
- **20 Aug** Custom interactive button for Preferred Sources.
- **29 Jul** Guide on analysing social and video platform content in Search
  Console.
- **24 Jul** Review snippet guideline against fake and undisclosed
  incentivised reviews.
- **14 Jul** Package tracking early-adopter programme closed.
- **7 Jul** Merchant listing docs cover `Product.category` and sale-price
  effective dates.
- **1 Jul** AMP docs simplified; AMP viewer, AMP Cache and signed exchanges
  removed.
- **17 Jun** Site move guide covers Change of Address for all subdomain
  variants.
- **15 Jun** llms.txt clarified as not used by Google Search; FAQ rich
  result documentation removed.
- **5 Jun** Guidance on evaluating third-party SEO tools and services.
- **27 May** Preferred Sources rolling out to AI Overviews and AI Mode.
- **20 May** `hasAdultConsideration` for merchant listings and variants.
- **15 May** New guide on optimising for generative AI features; spam
  policies apply to generative-AI responses.
- **8 May** FAQ rich result deprecated; removed from Search from 7 May 2026.
- **30 Apr** Preferred Sources in all Search languages.
- **14 Apr** Spam reports may lead to manual action.
- **13 Apr** New spam policy: back-button hijacking (malicious practices).
- **24 Mar** More properties for Discussion Forum and QA Page; robots meta
  handling outside `<head>` documented.
- **2 Mar** Preferred-image best practices (schema.org and `og:image` both
  used for thumbnails).
- **3 Feb** Googlebot file-size limits clarified and moved to crawler docs.
- **30 Jan** Preferred Sources documentation added.
- **6 Jan** Practice-problem structured data docs removed.

## 2025

- **15–18 Dec** JavaScript guidance clarified for noindex, canonicalization
  and non-200 status codes; more crawl docs migrated.
- **9 Dec** Core updates described as smaller, continuous updates.
- **20 Nov** Crawler docs moved to developers.google.com/crawling.
- **19 Nov** Discover Follow feature guidance removed.
- **12 Nov** Google-Pinpoint fetcher; shipping policy markup docs.
- **5 Nov** Practice problem structured data deprecated; Dataset markup used
  only by Dataset Search.
- **3 Nov** Google-CWS user-triggered fetcher.
- **15 Oct** Read Aloud product list updated.
- **9 Oct** Google-NotebookLM user-triggered fetcher.
- **9 Sep** Docs removed for course info, estimated salary, learning video,
  special announcement, vehicle listing.
- **28 Aug** JavaScript-based paywall guidance.
- **20 Aug** Google-CloudVertexBot crawler.
- **15 Aug** AI Overviews counted in Search Console Performance reports.
- **1 Jul** Google Read Aloud user agent updated.
- **16 Jun** AI Mode traffic counted in Search Console totals.
- **12 Jun** Deprecation banners for book actions, course info, estimated
  salary, ClaimReview, learning video, special announcement, vehicle listing.
- **11 Jun** Multilingual docs: robots.txt-blocking of auto-translated pages
  section removed.
- **4 Jun** SafeSearch guidance revamped; blocking Googlebot from video files
  may lower ranking.
- **21 May** New docs on AI features and on generative-AI content.
- **25 Apr** Google-Extended description clarified; Googlebot-News does not
  affect the News tab.
- **24 Apr** `EnergyConsumptionDetails` replaced by `Certification`.
- **23 Apr** Special announcement structured data deprecated (31 Jul 2025).
- **27 Mar** "AI while browsing" removed from paywall docs.
- **7 Mar** Page Annotations removed from "control what you share".
- **5 Mar** AI Mode added to robots meta docs.
- **13 Feb** Price encoding guidance (`priceType`, beta `validForMemberTier`)
  for merchant listings.
- **22 Jan** Breadcrumbs documented as desktop-only.
- **15 Jan** Recommend accepting only reviews with a comment and author name.
